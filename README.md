# Space Cadet Typing

A free typing game for young kids (grade 1-2). Learn the keyboard, build a rocket on your launch pad, and unlock new places and abilities along the way.

Plain HTML, CSS and JavaScript. No server, no build step, no accounts. Progress is saved in the browser (localStorage).

## Play it locally

Open `index.html` in a browser (double-click it). That's it.

## Publish it

This repo is meant for GitHub Pages: push it to a repo named `typingtutor`, then in the repo settings turn on Pages (deploy from the `main` branch, root folder). It will be served at puncraft.ca/typingtutor.

## Notes

- Needs a real keyboard (laptop or desktop).
- Progress lives in the browser it was played in. Clearing browsing data erases it.
- Voice uses the browser's built-in speech. Voice and sounds can be turned off on the launch pad.

See `PLAN.md` for the full design and the build phases.
